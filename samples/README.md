# Sample Images

This directory is reserved for sample/demo images to use in the SmartInspect AI demonstration.

## Why This Directory May Be Empty

The training dataset (MVTec-style industrial images) may have redistribution restrictions.
Before adding images here, verify the dataset's license permits redistribution.

## How to Add Sample Images

1. Pick representative images from the test split of your dataset.
2. Choose images that clearly show the defect (or clearly show a good product).
3. Name them descriptively: `bottle_good_01.png`, `cable_defective_01.bmp`, etc.
4. Add a maximum of 2-3 images per product category.
5. Use only images from the test set (never training images) for demo purposes.
